Risk Telemetry SDK — Example Assessment

This page demonstrates how to embed sdk/risk-telemetry-sdk.js into a simple assessment. It sends metadata-only events to your existing backend endpoint: POST /v1/events/ingest.

Candidate consent placeholder: this demo collects behavioral telemetry metadata for assessment integrity. It does not capture webcam, audio, screen recordings, answer text, or clipboard contents.

1) Setup

For hosted demos, point this to your deployed backend URL. For local development, use http://127.0.0.1:8000.
